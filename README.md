# LastTable

LastTable is a real-time table booking app. It shows restaurant tables that are free right now, and restaurants pay only for genuinely new diners.

**The official home is the website: [lasttable.ie](https://lasttable.ie) (Ireland) and [lasttable.ae](https://lasttable.ae) (UAE).** This repository holds the public text of our help pages; the website versions are the official ones.
